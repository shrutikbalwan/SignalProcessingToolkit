# ESP32 Predictive Maintenance Workbench

This tutorial runs the complete acquisition-to-diagnosis workflow without
hardware, then explains how to substitute an ESP32 serial source.

```
ESP32 accelerometer/microphone
  -> timestamped serial packets
  -> calibration and DC removal
  -> stateful SOS band-pass
  -> envelope and FFT/envelope spectrum
  -> engineering measurements
  -> ONNX or deterministic anomaly model
  -> dashboard and events
  -> session/report/embedded export
```

## Run the deterministic demo

```python
from signal_processing_toolkit.demo import ExperimentConfig, PredictiveMaintenanceWorkbench

workbench = PredictiveMaintenanceWorkbench(ExperimentConfig(faulty=True, seed=7))
result = workbench.run()
workbench.save(result, "workbench-session")
print(workbench.report(result))
```

The simulated source generates the same packetized signal for a fixed seed,
fragments packets like a serial transport, and parses them with the production
binary protocol. `PredictiveMaintenanceWorkbench.reopen()` restores the
recording and configuration. Re-running with the same configuration produces
identical raw and processed samples; measured host latency may naturally vary.

## Hardware and model substitution

Use `SerialSensorSource` with the binary format documented in
[acquisition.md](../api/acquisition.md). The default model is intentionally
small and deterministic for the demonstration. A validated `.onnx`/`.ort`
`EdgeModel` can be supplied behind the same `predict(windows)` contract.
For the actual ONNX path, install the `ai` extra and generate the reproducible
model with `python examples/edge_ai_motor_anomaly/build_demo.py --output model`.
Use `PredictiveMaintenanceWorkbench.with_onnx_model(...)` with a matching
2048 Hz configuration.

The exported filter header/source and test vectors are generated by the
embedded export subsystem. MAC counts and latency values are estimates or host
measurements; they are not cycle-accurate ESP32 claims.

## Example recordings and licensing

Healthy and faulty recordings are reproducible fixtures generated by
`SimulatedMaintenanceSource` using seed `7` and `faulty=False/True`. They are
synthetic, contain no third-party data, and are released under the repository's
MIT license. Generate local `.npz` sessions with the code above rather than
committing large binaries.
