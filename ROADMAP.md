# Roadmap

This roadmap is planning information, not a claim that an item is implemented.
Implemented behavior is documented in the API guides and covered by tests.

## Near term

- Production Qt dashboard for the predictive-maintenance workbench.
- Hardware-in-the-loop ESP32 and audio acquisition fixtures.
- Multi-input graph nodes and richer pipeline project persistence.
- Reproducible benchmark collection on named ESP32 targets.

## Longer term

- Plugin marketplace and signed plugin packages.
- Cross-platform packaged desktop installers.
- Expanded embedded code generation for optimized CMSIS/ESP-DSP kernels.
- Maintained public example datasets with provenance and licenses.
